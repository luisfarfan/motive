# mixed-example

Candidato modular CreatorPack v1. Validación real del crate, sin instalación.
`report.json` enumera selección, referencias retiradas, reglas deshabilitadas,
mapas de IDs y presupuesto. `preview/` es aproximación de diseño.

Consumo: {'scenes': 1, 'sources': 3, 'layers': 3, 'texture_bytes': 38776832, 'video_sources': 0}. Capturas y proyecto existente se suman
antes de instalar. La combinación completa 6 + 6 se rechaza, sin truncar.
Los PNG son contenido original GPL-3.0-or-later de Creator Experience;
se copiaron únicamente los referenciados. Los manifests originales no cambian.
